# Campus Registration -
I created a Python program that calculates campus event registration costs based on participant type, registration day, workshop selection, and evening-session attendance. I used if/elif/else statements, Boolean expressions, and calculations to determine fees, discounts, and the final registration category.

**What the program includes:**
Student, employee, and guest registration fees
Early registration discounts
Optional workshop fees
Evening parking fees
Final registration cost
Registration categories (Budget, Standard, and Premium)

**What I learned:**
Using if/elif/else statements
Working with Boolean expressions (and and or)
Using user input
Performing calculations with variables
Applying discounts and additional fees
Displaying formatted results
